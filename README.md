# 土派 Tapa

一个基于 Web 的土派（Tapa）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5209/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 涂黑部分格子，所有黑格必须上下左右连成一片
- 任意 2×2 区域不能全黑
- 数字格为白，其周围八格按顺时针看，黑格连续段长度必须与数字完全一致

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 黑 → 叉 → 空 |
| 右键点格 | 直接标叉 / 清除 |
| 按住拖动 | 连续涂写同一状态 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **自定义题板**：在侧边栏编辑题面，尺寸上限 **40×40**，载入后即可游玩，支持保存、编辑、删除与唯一解校验
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

  game/

## 图片识别导入

用 Playwright + Edge 识别题面图片里的网格与数字线索，生成题库格式后预览 / 写入。

```bash
# 只识别 + 预览（会先求解出参考解，大图较慢）
npm run import-image -- 题面.png

# 只识别网格与线索
npm run import-image -- 题面.png --dry

# 求解并确认唯一解（35×35 这类大图可能超时，会给出警告）
npm run import-image -- 题面.png --verify --timeout 300000

# 追加到题库（写入 src/game/imported-puzzles.ts，npm run gen 不会覆盖）
npm run import-image -- 题面.png --name "我的土派" --append
```

| 参数 | 说明 |
|------|------|
| `--name 名称` | 题库中显示的名称（默认「识图 · W×H」） |
| `--series 系列` | 系列名（默认「图片导入」） |
| `--difficulty 级别` | `easy` / `medium` / `hard` / `custom`（默认 `hard`） |
| `--size N` | 正方形网格边长；默认自动识别 |
| `--width N` / `--height N` | 非正方形题图的宽/高，可只给一边 |
| `--map 行,列=数字串` | 人工覆盖某格线索（行列从 1 开始；每个字符是一段，如 `122` 表示 (1,2,2)，`0` 表示清空） |
| `--append` | 写入 `src/game/imported-puzzles.ts` |
| `--verify` | 唯一性检查（超时会警告，不阻断导入） |
| `--dry` | 只识别网格与线索，不求解、不写入 |
| `--timeout MS` / `--max-nodes N` | 求解时间 / 节点上限（默认 180000ms / 3000000，大图请放宽） |
| `--edge PATH` | 指定 Edge 路径（默认自动探测） |

识别流程：投影找网格线 → 每格 8 连通域得到数字字形 → 多套无衬线字体模板 IoU 匹配数字 → 按行/列排序得到线索顺序。
Tapa 线索的「先后次序不分」，而本项目引擎从 N 起算的规范方向解释线索，所以导入时会先用循环语义解出一个解，
再用解把每个线索旋转成规范方向；导入的题面与本项目求解器完全兼容。`types.ts` 的 `PATTERNS` 末尾补充了
`6/7/8` 单段、四段 `(1,1,1,1)` 与旋转 `(2,1,2)`，以支持真实题图（追加在末尾，不影响已有题目编码）。

## 题板尺寸与形状支持

- **题面模型**：`width × height` 线索网格（row-major），宽高独立，支持非正方形。
- **内置题库**：8×8（正方形）。
- **自定义题板**：宽 5–40、高 5–40，任意非正方形组合；线索值 1–9 对应段长序列。
- **识图导入**：自动按网格线识别行列，`--width/--height` 可覆盖；`month.png`（35×35、232 个线索格）识别成功。
- **异形棋盘**：不支持。Tapa 线索按每格 8 邻域解释，棋盘是完整矩形；没有「棋盘外空格」语义。
  自定义题板里「线索格 / 非线索格」只是线索密度不同，不是异形边界。
- **验证**：`npm run build`、`npm run check` 通过；内置参考解与逻辑计划合法；
  自定义非正方形（6×7、7×5、9×6、5×5、40×5 / 5×40 极限）编解码、渲染比例、编辑回填、求解闭环实测通过。
- **限制**：40×40 级别的回溯求解可能超时（有节点与时间上限）；识图大题默认无参考解。
